Рабочий материал для интервью и демонстраций: слева — как боль звучит от подрядчика, в центре — чем отвечает система, справа — измеримый эффект.

«Заказчик задержал оплату — узнали поздно» Отчёт просроченной задолженности с учётом отсрочек по каждому договору Дебиторка на любую дату, дни просрочки по каждому заказчику
«Не знаем, хватит ли денег на зарплату и поставщиков» Платёжный календарь: план/факт по строкам, автоподбор зарплаты и счетов поставщиков, кассовый поток по дням с подсветкой дефицита Кассовый разрыв виден за неделю, а не по факту
«Платежи идут хаотично, без плана» График платежей с категориями (этап заказчика, зарплата, поставщик, налоги); проведение накладной автоматически создаёт плановый платёж (дата + отсрочка договора) Каждая накладная сама попадает в план платежей

Объект и факт работ

«Данные с объекта едут бумагой и фото, теряются» Ежедневный отчёт прораба в системе; объект работает офлайн, синхронизируется с офисом пакетами Факт работ в базе в день выполнения, без двойного ввода
«Фактическую себестоимость узнаём после стройки» Расчёт себестоимости по элементам затрат (материалы, зарплата, машины, субподряд, накладные): план/факт, рентабельность по объектам и договорам Маржа объекта под контролем в ходе работ
«Отклонения от сметы замечаем слишком поздно» Отчёт отклонений с настраиваемым порогом %, drilldown из любой цифры до исходного документа Перерасход видно сразу, а не на итогах

«Акты и отчёты заказчику делаем вручную неделями» Печать акта по смете и акта по дневному отчёту (PDF/Excel) из уже введённых данных Документ формируется одной кнопкой, без перепечатки
«Нужны именно КС-2 / КС-3, а не ваши акты» Печатные формы КС-2/КС-3 на основе сметы и отчётовдоработка Знакомые формы для заказчика и банка
«Сметы в ГрандСмете/Excel — данные не связаны с учётом» Импорт смет из Excel/текста с автосозданием работ и единиц; каталог работ с ценами и нормами трудоёмкости Одна база работ от сметы до факта
«Переносить НСИ из 1С некому и дорого» Есть импорт справочников и спецификаций из DBF-выгрузки 1С; прямой коннектор обмена с 1С:Бухгалтериейдоработка Старт на готовой базе, бухгалтерия получает документы автоматически

Аналитика и контроль

Боль (голос заказчика)Как решает CTMЧто получите
«У каждого свой Excel, цифры не сходятся» Единая база, отчёты (карточка себестоимости, ОСВ по затратам и взаиморасчётам, рентабельность) с экспортом CSV/Excel, дашборд Все считают по одним и тем же цифрам
«Прорабы 1С не осилят» Понятный веб-интерфейс с вкладками; роль «прораб» видит только свои объекты и табели Обучение прораба — за один день
«Хочется BI, прогнозы, автоматизацию поля» Открытый REST API и read-витрина данных; мобильное приложение прораба, GPS-мониторинг техники, банковские выписки, ЭДОдоработка Аналитика и автоматизация без ограничений продукта
Как пользоваться: на интервью отмечайте, какие фразы произносит заказчик, — совпадение с левой колонкой = готовый сценарий демонстрации CTM. Частые боли, не покрытые таблицей, — источник доработок и УТП.
