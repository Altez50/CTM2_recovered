Заказчик:

Почитай про доработки - это сложно сделать?

Что можно доработать (и продать как преимущество)
Исходя из архитектуры и анализа файлов, вот что можно быстро добавить и сделать частью УТП.
Быстрые доработки (1–2 недели):
КС-2 / КС-3 / М-29 — печатные формы уже есть (смета, акт), нужно только адаптировать их под унифицированные формы. Это «хлеб» для строителей — заказчик ждёт именно эти документы.
Импорт из ГрандСметы / Smeta.ru
 — технически это тот же импорт смет из Excel/XML, нужно только настроить парсер под их форматы.
Мобильное приложение прораба — у вас уже есть веб-интерфейс, который работает на телефоне. Можно сделать PWA (Progressive Web App) — это добавит иконку на рабочий стол, push-уведомления и офлайн-режим.
Средние доработки (1–2 месяца):
Интеграция с банковскими API — автозагрузка выписок, подача платежей. Это закроет боль «каждый день вбиваем выписку вручную».
Telegram-бот — уведомления о просрочках заказчиков, кассовых разрывах, отклонениях факт/план. Это дешёвый способ увеличить ценность продукта.
ЭДО (Диадок, СБИС, Контур) — отправка актов и счетов-фактур заказчикам прямо из системы. Это снимет боль «печатаем, сканируем, отправляем».
Долгосрочные доработки (от 3 месяцев):
BI-аналитика — подключите Yandex DataLens или Power BI к витрине данных, чтобы клиент строил дашборды без программиста.
AI-функции — прогноз кассовых разрывов, распознавание входящих счетов, автоматическое выявление перерасхода.
Мультикомпания / холдинг — чтобы управлять несколькими юрлицами из одного интерфейса.

Мысли разработчика:
доработки выше-реально, пока не начинается Контур, их АПИ требует подписки и стоит 20к в год вроде, классика-прогнать через типовую 1с:Бухгалтерию, там дешевый модуль интеграции.Второй путь-через веб версию Диадок.

Тарифы требуют обкатки на реальной обработке требований, пока можно предложить классический консалтинг: приложение "как есть" бесплатно, если хостится у клиента, если нет - 1-2 тр/мес на всех (в процессе обкатки может меняться, если мощностей не хватет). Доработки по отдельному договору 2500/час с предварительным согласованием объема и характера доработок.

## Оценка объёма доработок (на основе архитектуры CTM, 1 fullstack-разработчик, ставка 2500 ₽/ч)

Оценки — чистая разработка без ревью/UAT; в скобках цена по ставке.

### «Быстрые» (заявлено 1–2 недели)

| Доработка | Что уже есть в CTM | Объём | Вердикт заявке |
|---|---|---|---|
| **КС-2 / КС-3 / М-29** | Печатный движок (PDF + Excel-шаблоны со стилем), акт по смете и по дневному отчёту; данные для М-29 = лимит из спецификаций + факт (регистры planned/actual costs) | КС-2 ~18 ч, КС-3 ~10 ч (справка по данным КС-2), М-29 ~20 ч → **48 ч ≈ 6 раб.дней (120 т.р.)** | Подтверждается. Риск: клиенты захотят свои шапки/подписантов — заложить настройку |
| **Импорт ГрандСмета / Smeta.ru** | Универсальный импорт ТЧ смет (TSV/JSON/XLSX) с автосозданием работ/единиц + профили сопоставления | Вариант А — из Excel-выгрузки ГрандСметы через профили: **24 ч (60 т.р.), 3 дня**. Вариант Б — нативный XML-парсер: 40–48 ч. Начать с А | Подтверждается при подходе «Excel-выгрузка». Нативные форматы закрыты/вариативны |
| **PWA (мобильный прораб)** | Веб-клиент уже адаптивен; офлайн-архитектура узлов + relay существуют, но для браузера офлайн-слой новый | Оболочка (иконка, кеш, push): 40 ч (100 т.р.). Адаптация ключевых экранов (дневной отчёт, табель) под телефон: +40–60 ч. Честный офлайн-ввод: +60 ч и отдельный проект | Оптимистична: «иконка+push» — да, за неделю; «офлайн-режим» — нет, без 100+ ч |

### Рекомендуемый порядок (максимум продаж на минимум часов)

1. КС-2/КС-3/М-29 (48 ч) — «хлеб», спросят первым делом
2. Telegram-бот (48 ч) — дёшево, эффект «система сама звонит»
3. Импорт ГрандСметы через Excel (24 ч) — снимает барьер входа с существующими сметами
4. Банковская выписка формата 1С (48 ч) — ежедневная рутина
5. BI-витрины + DataLens (32 ч) — «вау» для руководителя за копейки

Пакет 1–5: **~200 ч ≈ 5 недель ≈ 500 т.р.** — и это уже закрывает почти все «боли» из интервью.

PWA-офлайн, полная ЭДО-интеграция, мультикомпания — только после подтверждённого спроса и предоплатного договора.
