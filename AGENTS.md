# Project rules

- Do not use any `1c-skills` skills while working in this project.
- Проверяй пятичасовой лимит через get_usage_limits в начале каждого запуска, перед новым этапом и каждые 5 минут длительной работы. Выбирай окно windowDurationMins = 300.
При usedPercent >= 85 не начинай новые операции. Доведи текущую атомарную операцию до безопасного завершения, сохрани изменения, состояние очереди и точку продолжения. Сообщи о паузе и времени сброса resetsAt, затем заверши ход. Продолжай после сброса лимита и повторной проверки доступности.
Если счетчик недоступен, не считай использование нулевым.
